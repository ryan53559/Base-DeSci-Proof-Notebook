# Human and AI Collaboration / 人類與 AI 分工紀錄

## Honest disclosure / 誠實揭露

This project was implemented with extensive AI coding assistance. The AI wrote
most implementation drafts and documentation under the builder's direction.
The running product does not use an AI API.

本專案大量使用 AI 協助寫程式。AI 依照開發者的需求與決策產生大部分程式初稿
與文件；實際運作的網站本身沒有使用 AI API。

## Human contribution / 開發者的實際貢獻

- Chose the DeSci integrity problem and the audience of students and researchers.
- Required local hashing, no file upload, no IPFS, and testnet-only development.
- Selected Base Sepolia, the three core features, bilingual language, and plain wording.
- Decided that public text must carry an explicit privacy warning.
- Requested and evaluated the Chainlink confidential embargo-rule extension.
- Created and controlled the test wallet, approved deployment, and checked visible results.
- Directed UI revisions, questioned limitations, and required honest discussion of gas,
  wallets, patents, scientific truth, AI use, and sponsor eligibility.
- Will personally record the narration and submit the final project.

## AI-assisted contribution / AI 協助內容

- React, TypeScript, CSS, Solidity, test scripts, and GitHub Actions drafts.
- Debugging dependency, browser, wallet, contract, and deployment problems.
- Bilingual interface text, architecture explanation, report, and video draft.
- Test execution and evidence organization.

## Safety boundary / 安全界線

AI never receives or requests a recovery phrase, private key, password, or real
research file. Wallet signatures remain human-controlled. Generated code is
accepted only after build, compile, browser, or chain evidence is checked.

AI 不會取得或要求助記詞、私鑰、密碼或真實研究檔案。錢包簽名由開發者本人控制。
程式只有在建置、編譯、瀏覽器或鏈上證據完成檢查後，才會被列為已完成。
